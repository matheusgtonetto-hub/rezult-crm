Enviar conversões reais para o Meta Ads via CAPI

Use estes dois modelos para devolver ao Meta Ads os eventos que realmente importam para o seu negócio: Lead qualificado (quando um negócio avança de etapa) e Purchase (quando um negócio é ganho). Os eventos chegam diretamente pelo servidor — sem depender do pixel no site nem de cookies.

1. O que você vai configurar

A Conversions API (CAPI) do Meta permite que o Rezult CRM envie eventos de conversão diretamente dos servidores — sem depender do pixel no navegador do lead. Isso torna o rastreamento mais confiável: bloqueadores de anúncios, iOS 14+ e navegação em modo privado não afetam esses eventos.

Com essa integração ativa, o Meta recebe:

  • Evento Lead — quando um negócio é movido para a etapa que você definir como "qualificado".
  • Evento Purchase — quando um negócio é marcado como ganho (inclui o valor do negócio, se preenchido).

Por que isso importa? O Meta usa esses eventos para otimizar a entrega dos seus anúncios. Quanto mais próximos da conversão real, mais inteligente fica o algoritmo — e menor o custo por resultado.

2. Pré-requisitos

  • Uma conta no Meta Business Suite com acesso à conta de anúncios.
  • Um Pixel do Meta já criado (mesmo que não esteja instalado no site).
  • Acesso para gerar um Token de acesso no Gerenciador de Eventos do Meta.
  • Acesso ao Rezult CRM com permissão para criar automações e acessar Configurações.

Não precisa de pixel no site. A Conversions API funciona independentemente do pixel estar instalado nas suas páginas. Ela usa apenas o ID do pixel como identificador da sua conta de anúncios.

Etapa no Meta

3. Parte 1 — Obter o Pixel ID e o Access Token no Meta

Você vai precisar de dois dados do Meta: o ID do pixel e um token de acesso. Ambos ficam no Gerenciador de Eventos.

  1. Abra o Gerenciador de Eventos

    Acesse business.facebook.com → menu de hambúrguer → Gerenciador de Eventos. Confirme que está na conta de anúncios correta.

  2. Selecione seu pixel

    No painel esquerdo, clique na fonte de dados (pixel) que você usa nas campanhas. O nome geralmente é o nome da sua empresa ou da campanha principal.

  3. Copie o ID do pixel

    Logo abaixo do nome da fonte de dados, você encontra o ID do pixel — um número com cerca de 15 dígitos. Copie e guarde esse número.

  4. Acesse as configurações da Conversions API

    Ainda na tela do pixel, vá na aba Configurações. Role a página até encontrar a seção Conversions API (API de Conversões).

  5. Gere um token de acesso

    Clique em Gerar token de acesso. O Meta vai mostrar um token longo — é uma sequência de letras e números com mais de 100 caracteres. Copie imediatamente e guarde em local seguro, pois ele não será exibido novamente.

Guarde o token em lugar seguro. Ele dá acesso para enviar dados ao seu pixel. Não compartilhe publicamente. Se for comprometido, você pode revogar e gerar um novo no mesmo painel.

Etapa no Rezult CRM

4. Parte 2 — Configurar as chaves no Rezult CRM

Agora você vai informar ao Rezult CRM quais são o seu Pixel ID e o token de acesso.

  1. Vá em Configurações → Integrações → Meta Ads

    No menu lateral do Rezult CRM, clique em Configurações e depois em Integrações. Localize o card Meta Ads — Conversions API.

  2. Adicione o primeiro pixel

    Clique em + Adicionar pixel. Dê um nome para identificar este pixel (ex.: Principal ou o nome da campanha), cole o ID do pixel e cole o Access Token. Confirme.

  3. Verifique a conexão

    Após salvar, o sistema envia um evento de teste para o Meta. Se tudo estiver correto, você verá o status Ativo ao lado do pixel. Caso apareça erro, confira se o token foi copiado completo, sem espaços no início ou no fim.

Múltiplos pixels. Se você gerencia mais de uma conta de anúncios, pode adicionar um pixel por conta. Cada automação escolhe qual pixel usar na hora de configurar a ação de envio.

Etapa no Rezult CRM

5. Parte 3 — Modelo "Lead qualificado"

Este modelo envia o evento Lead para o Meta sempre que um negócio é movido para a etapa que você definir como a etapa de qualificação. Use-o para dizer ao Meta quais leads do seu funil realmente mostraram interesse.

  1. Crie a automação pelo modelo

    Vá em Automações → Nova automação → aba Modelos. No grupo Meta Ads, selecione Meta Ads · Lead qualificado. Dê um nome (ex.: Meta — Lead qualificado), escolha o grupo e confirme.

  2. Configure o gatilho

    O gatilho já vem como Negócio movido. Clique no bloco de início e selecione a etapa de destino que representa um lead qualificado no seu funil (ex.: Proposta enviada, Em negociação). Apenas negócios que chegarem a essa etapa dispararão o evento.

  3. Configure a ação de envio

    Clique no bloco de ação Enviar evento para Meta Ads. Confirme que o evento está como Lead e selecione o pixel que você cadastrou na Parte 2. Salve.

  4. Ative a automação

    Ligue o interruptor Ativa. A partir deste momento, toda vez que um negócio for arrastado para a etapa configurada, o evento será enviado ao Meta.

Qual etapa escolher? Escolha a etapa que representa o momento em que um lead deixou de ser um curioso e mostrou interesse real — por exemplo, quando entrou em negociação ou recebeu uma proposta. Evite a primeira etapa do funil, pois isso enviaria o evento para todos os leads, sem filtro de qualidade.

Etapa no Rezult CRM

6. Parte 4 — Modelo "Negócio ganho (Purchase)"

Este modelo envia o evento Purchase para o Meta sempre que um negócio é marcado como ganho. É o sinal mais valioso que você pode dar ao algoritmo: uma venda concreta. Se o negócio tiver valor preenchido, o valor é enviado junto — o Meta usa isso para calcular o ROAS das campanhas.

  1. Crie a automação pelo modelo

    Vá em Automações → Nova automação → aba Modelos. No grupo Meta Ads, selecione Meta Ads · Negócio ganho (Purchase). Dê um nome (ex.: Meta — Negócio ganho), escolha o grupo e confirme.

  2. Confira o gatilho

    O gatilho já vem configurado como Negócio ganho — não há nada para alterar aqui. Qualquer negócio marcado como ganho no CRM vai disparar este fluxo.

  3. Configure a ação de envio

    Clique no bloco de ação Enviar evento para Meta Ads. Confirme que o evento está como Purchase e selecione o pixel correto. Salve.

  4. Ative a automação

    Ligue o interruptor Ativa.

Preencha o valor do negócio. Se você preencher o campo valor ao marcar um negócio como ganho, esse valor é enviado automaticamente no evento Purchase. O Meta usa esses dados para calcular o retorno sobre o investimento em anúncios (ROAS) e otimizar para compradores de maior valor.

7. Parte 5 — Confirmar que os eventos chegaram ao Meta

Após ativar as automações, você precisa confirmar que o Meta está de fato recebendo os eventos. Há duas formas de verificar.

Pelo Gerenciador de Eventos do Meta

  1. Acesse o Gerenciador de Eventos

    Em business.facebook.com, vá em Gerenciador de Eventos e clique no seu pixel.

  2. Veja a aba "Atividade"

    Na aba Atividade, você verá um gráfico com os eventos recebidos nas últimas 24 horas. Procure pelos eventos Lead e Purchase.

  3. Use a ferramenta de teste de eventos

    Na aba Testar eventos, você encontra a ferramenta de teste em tempo real. Para testá-la: mova um negócio de teste para a etapa configurada (evento Lead) ou marque um negócio como ganho (evento Purchase). Em segundos, o evento deve aparecer na lista da ferramenta de teste.

Pelo Rezult CRM

  1. Abra a automação

    Em Automações, clique na automação de Meta Ads que você criou.

  2. Confira as estatísticas do bloco

    Cada bloco mostra quantas vezes foi executado com sucesso e quantas vezes apresentou erro. O bloco Enviar evento para Meta Ads deve ter ao menos uma execução para cada teste que você fez.

  3. Clique em "Ver logs"

    Se houver algum erro, clique em Ver logs para ver o detalhe — o log mostra o código de resposta da API do Meta e, em caso de falha, a mensagem de erro exata.

Eventos podem demorar até 20 minutos para aparecer no painel do Gerenciador de Eventos em modo de produção. Mas na aba Testar eventos, eles aparecem em segundos.

8. Avançado — múltiplos pixels e etapas

Usando pixels diferentes por funil

Se você gerencia campanhas de produtos ou mercados diferentes com pixels distintos, adicione todos os pixels em Configurações → Integrações → Meta Ads. Na hora de configurar a ação de envio em cada automação, basta selecionar o pixel correspondente.

Enviar Lead para múltiplas etapas

Para disparar o evento Lead em diferentes momentos do funil, crie uma automação separada para cada etapa relevante. Por exemplo: uma automação para a etapa Proposta enviada (Lead) e outra para Contrato assinado (também Lead). O Meta receberá os dois eventos e usará o mais próximo da venda para otimizar.

Não duplique o evento Purchase. Crie apenas uma automação de Purchase por funil de vendas. Enviar o mesmo evento mais de uma vez para o mesmo negócio pode distorcer os dados de ROAS no painel do Meta.

Combinando com o evento de Lead do formulário

Se você já usa o modelo Lead Formulário Webhook para capturar leads de formulários do Meta, os dois podem coexistir: o formulário envia leads para o CRM, e as automações de Meta Ads devolvem ao Meta os eventos de qualificação e venda. O ciclo fica completo.
