Gatilhos: quando a automação dispara

O gatilho é o ponto de partida de toda automação. Ele responde a uma única pergunta: “o que precisa acontecer para a automação começar a rodar?” Aqui você conhece cada tipo e aprende a filtrá-los para disparar só na hora certa.

8 min de leitura Nível: iniciante

Neste tutorial

  1. O que é um gatilho
  2. Como escolher o gatilho

1. O que é um gatilho

Pense no gatilho como o sensor da automação. Ele fica “de olho” em um evento específico do seu CRM. No instante em que esse evento acontece, o sensor dispara e todos os blocos seguintes começam a executar, em ordem.

Cada automação tem um gatilho — é sempre o primeiro bloco, à esquerda. Sem gatilho, a automação nunca roda.

2. Como escolher o gatilho

  1. Clique no bloco de início

    Ao criar a automação, o primeiro bloco já é o de gatilho. Clique nele para abrir a lista de gatilhos.

  2. Escolha a categoria

    Os gatilhos são organizados em categorias (Negócios, Leads, Mensagens...). Selecione a que combina com o evento que você quer monitorar.

  3. Selecione o evento

    Dentro da categoria, clique no gatilho desejado — por exemplo, Lead criado ou Negócio ganho.

  4. Configure os filtros

    Defina os detalhes (qual pipeline, qual etapa, qual tag). Veja a próxima seção.

3. Filtros: disparar só na hora certa

Sem filtro, um gatilho como “Negócio movido” dispararia para qualquer movimentação, em qualquer etapa. Quase sempre você quer algo mais específico. Por isso muitos gatilhos têm campos de configuração:

  • Negócio movido → escolha a pipeline e a etapa de destino. Só dispara quando o negócio cai naquela etapa.
  • Tag adicionada / removida → escolha qual tag. Só dispara para aquela etiqueta específica.
  • Atendente atribuído → opcionalmente, qual atendente.

Deixe sem filtro de propósito? Se você não preencher o filtro, o gatilho dispara para todos os casos. Isso é útil às vezes (ex.: “qualquer lead criado”), mas confira sempre, para a automação não rodar onde não deveria.

Eles seguem a mesma lógica: escolher o evento e configurar os filtros.

5. Regras importantes

O gatilho só “liga” se a automação estiver Ativa Mesmo configurado, nada acontece enquanto o interruptor da automação estiver desligado.

Dados do gatilho viram variáveis Quando o gatilho dispara, ele “carrega” os dados do evento (o lead, o negócio, a conversa). Esses dados ficam disponíveis nos próximos blocos como variáveis {{ }} — por exemplo, o nome do lead que acabou de ser criado.

Cuidado com gatilhos que a própria automação provoca Se uma automação com gatilho “Tag adicionada” também adiciona uma tag, ela pode chamar a si mesma. Planeje o fluxo para evitar loops.

Com o gatilho definido, é hora de dizer o que fazer. Vamos às Ações.
